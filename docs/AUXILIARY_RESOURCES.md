# Auxiliary resources and unchanged formats

The auxiliary audit classifies 22 inventory candidates through 76 bounded
native cases. Four global program roots and one contained operand are commands;
two actor fields and three event-flag entries are numeric. Ten full-width digits
are nickname suffix assets. The kana conversion alphabet passes all 55 mappings.
The original compact name defaults are confirmed on Japanese code: the English
name component deliberately replaces their selector with the seven-letter
Torneko default, while preserving the retired source records.

[Auxiliary verification](../build/completion/aux-resource-audit/native-verification.json)
records selected fields, command fetches, copied bytes, guards and input hashes.
The complete emulator state is restored between cases. Event actions and flag
updates are not executed, and these checks do not establish natural reachability.

A further 64 sources need no authored English: result-key templates, positioning,
colour and numeric formats, separators, heart markers, and original English
diagnostics. [Reviewed consumers](../build/completion/neutral-resource-audit/source-review.json)
and [native literal checks](../build/completion/neutral-resource-audit/native-verification.json)
record their precise source/pointer ownership. These checks confirm one literal
load per source; they are not additional complete display tests.

The apparent eta prefix in result messages is a heart in the actual font.
Its original bytes remain intact. The unusual star in a separate unresolved
battle candidate really is a star; that phrase remains open for context review.

All source bytes stay unchanged in the accepted text-polish ROM. The inventory
now has 8,417 authored English entries, 800 retained entries and 101 open entries.
Other resources outside the inventory and natural gameplay coverage remain open.
Exact occupied ranges and temporary fixtures are in the [memory map](MEMORY_MAP.md).
