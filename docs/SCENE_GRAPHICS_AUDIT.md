# Background graphics found by the text extractor

Native checks identify 71 extraction candidates as tile pixels or metatile
indexes. Apparent Japanese characters and short Latin strings in these byte
ranges are decoding coincidences. The assets retain their original bytes.

The proof selects the original scene through `0806C5F0`, copies its 36-byte
descriptor through the native loader, and follows its background header.
The native format selector distinguishes 2×2 from 3×3 metatiles. Header counts
include a blank entry generated by the game, so stored asset spans use count
minus one. Using the unadjusted count would incorrectly include adjacent data.
Native copy loops copy every complete tile/index unit covering each candidate
into guarded temporary memory. All 71 candidates pass exact byte comparisons,
format-state checks and surrounding-memory guards in the accepted ROM.

[Candidate ancestry](../build/completion/remaining-ui/research/scene-graphics-candidates.json)
records scene/header/asset spans; [native verification](../build/completion/scene-graphics-audit/native-verification.json)
records the selected owners, copied bytes and ROM, fixture and tool hashes.
The [memory map](MEMORY_MAP.md) indexes source and temporary RAM ranges.

These are controlled loader checks, not a claim that every scene was reached
naturally. They establish resource type without changing graphics or approving
any source space for insertion. The ordinary inventory now contains 8,417
authored English entries, 714 retained entries and 187 open candidates.
