## Reference order

1. Use modern official Dragon Quest English, with **XI / XI S as the baseline**
   for shared items, monsters, spells and terminology.
2. For gaps, consult other modern official localizations, including the remakes
   and Monsters games. Record the particular game/version. Consider later name
   revisions individually; a differently named upgrade, weapon form or monster
   variant is not interchangeable with the original entity.
3. Use the official PS1 **Torneko: The Last Hope** as a fallback for terminology
   specific to these dungeon games when a suitable modern match is not found.
4. Japanese references and the SFC Torneko fan translation can help identify
   context, but do not establish modern official English. The supplied partial
   Torneko 3 patch remains a technical reference only, including its fonts.

Prefer official text, manuals or game captures. Fan-maintained wikis, databases
and walkthroughs can document an official game's wording, but label that
evidence as secondary. A search that finds no equivalent does not prove none
exists. Keep uncertain choices explicitly provisional rather than calling them
official. Record sources and the review date when adopting or revising a term.

## Identity and writing rules

- Match the Japanese name and entity, using the source row/item ID and context.
  Account for kana/kanji spelling differences; do not match by English
  resemblance alone. Enemy species, recolours, upgraded forms and nicknames
  need distinct entries when their identities differ.
- Preserve the official English localization's puns and wordplay when an exact
  species match exists. Japanese loanwords and literal meanings are identity
  clues, not replacement English names. Record the specific reference game,
  including XI S/Tickington-only appearances. Flag uncertain matches before
  inventing a new name; a name's wordplay does not establish Torneko 3 mechanics.
- Use the same name in item lists, descriptions, synthesis headings, dialogue
  and future enemy/ally screens. Update starter defaults too. Record the full
  name before measuring width; keep any necessary short label separate.
- Use sentence case for item labels, retaining proper names and acronyms.
  Use **defence** and, as needed, **armour** in the modern series style. Keep
  **HP**. Capitalization such as **Adventure Log** is our consistent UI style;
  **Log 1 / Log 2** and **Delete log** are established short menu labels.
- Translate effects from the **Torneko 3 Japanese source**, including targets,
  amounts, durations and exceptions. Other games supply naming references,
  not replacement mechanics or ready-made description paragraphs.
- Unidentified names are randomized disguises, not identified item identities.
  For example, **Red herb** here is the disguise あかい草, not evidence that a
  particular identified herb has another game's name or effect.
